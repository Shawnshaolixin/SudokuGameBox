## 1. 变现模型

**F2P 混合变现**:广告(主)+ IAP(次)+ 可选订阅。局内零广告是体验底线,也是与头部竞品的核心差异。

| 收入源 | 定位 | 优先级 |
|---|---|---|
| 激励视频广告(Rewarded) | 提示/续命/奖励翻倍 | P0 |
| 插屏广告(Interstitial) | 局间,强频控 | P1 |
| 横幅广告(Banner) | 谨慎,可全局关闭 | P2 |
| 去广告 IAP | 一次性买断 | P0 |
| 提示包 IAP | 消耗型 | P1 |
| Premium 订阅 | 去广告 + 无限提示 + 专属内容 | P1 |

---

## 2. 广告平台与中介

- **主 SDK**:Google AdMob + **UMP**(GDPR/英国 GDPR 同意管理)。
- **中介(Mediation)**:AdMob 中介接入 AppLovin、Unity Ads(ironSource)、Meta Audience Network,按 eCPM 自动优化;上线稳定后再逐步扩。
- **合规底线**:欧盟/英国用户先弹 UMP 同意,再初始化广告;未同意不展示个性化广告。

---

## 3. 广告位矩阵(Placement Map)

| 广告位 | 触发 | 频控(上限) | 说明 |
|---|---|---|---|
| Rewarded:免费提示 | 提示币耗尽点提示 | 每局 ≤ 3 次 | 核心激励点 |
| Rewarded:续命/解锁 | 失败重试 / 解锁高级难度 | 每会话 ≤ 2 次 | 减少挫败 |
| Rewarded:奖励翻倍 | 结算弹窗「翻倍提示币」 | 每局 1 次 | 高 eCPM 位 |
| Rewarded:补签 | 错过每日挑战补签 | 每日 1 次 | 留存工具 |
| Interstitial | 完成一局返回主菜单 | 每 4~6 分钟 ≥1 次 | 强频控,冷启动保护 |
| Banner | 主菜单底部(可关) | — | 低打扰,P2 再评估 |

- **频控原则**:去广告用户零广告;新用户前 3 局零插屏(冷启动保护);激励视频永不强制。

## 5. KPI 与基准(软启动验证目标)

| 指标 | 定义 | 行业基准(puzzle) | 本项目目标 |
|---|---|---|---|
| D1 留存 | 次留 | ~25-30% | **≥ 35%** |
| D7 留存 | 7 日留存 | ~8-10% | **≥ 12%** |
| D30 留存 | 30 日留存 | ~2-4% | **≥ 4%** |
| 会话时长 | 平均每会话 | 5-10 分钟 | ≥ 8 分钟 |
| ARPDAU | 日均活跃用户收入 | $0.05-0.15 | ≥ $0.10 |
| eCPM(激励) | 千次展示收入 | $8-15(US) | 跟踪 |
| IAP 转化率 | 付费用户占比 | 1-2% | 去广告 ≥ 2% |
| CPI | 单安装成本 | $0.5-2(激励量) | 记录,为 UA 决策 |

> 数据来源与行业基准可参考 [Playio 留存按品类](https://blog.playio.co/retention-by-game-genre) 与 [Mobile Games Benchmarks](https://gameindustrylibrary.com/documents/q1-mobile-games-benchmarks-2024/read?page=3)。

## 6. 数据埋点(事件字典)

### 6.1 命名规范(硬规则,新增事件前必读)

**Firebase Analytics 硬性字符限制(违反即被 SDK 静默拒收,DebugView/后台均不可见,无任何报错)**:
- 事件名仅允许 `[a-z0-9_]`、**字母开头**、总长 ≤40;`.` `/`、驼峰、大写、数字开头一律非法;参数名同限制,参数值无字符限制
- 真机教训(2026-09-05 清理):此前带点命名(`watersort.tutorial_step`、`UI/Popups/MoreGamesPopup.ui_show`)从未上报且全程无报错,排查时靠 DebugView 拉数才暴露——**埋点静默失效是最大的坑**

**命名规范**:全小写 snake_case `<模块>_<动作>[_<细节>]`,**模块前缀必带**(多玩法盒子需归属):
- 数独:`sudoku_level_start` / `sudoku_level_complete` / `sudoku_hint_used`
- 水排序:`watersort_ad_reward` / `watersort_coin_spend` / `watersort_tutorial_step`
- UI 自动埋点:事件名**固定 `ui_show`**,view 资源路径放参数——view.Id 含 `/` 与大小写,严禁拼进事件名(2026-09-05 前被拒收的正是这种拼法)

> **本节是事件命名唯一权威**;01/08/10/19 等文档中的旧命名(含点号)若与本节不符,以本节为准。

### 6.2 事件字典(实装,2026-09-05 校)

| 事件 | 触发 | 关键属性 |
|---|---|---|
| `services_initialized` | 启动链路打通(后台出现此事件 = SDK 验收信号) | — |
| `ui_show` | 任意视图展示(Router 自动上报,业务不手写) | view(资源路径) |
| `sudoku_level_start` | 数独开局 | difficulty, puzzle_id, source(daily/free) |
| `sudoku_level_complete` | 数独完局 | difficulty, time_sec |
| `sudoku_hint_used` | 数独用提示 | hint_type |
| `watersort_ad_reward` | 水排序激励视频发放(去广告伪直发也计) | placement(hint/extra_tube/double) |
| `watersort_coin_spend` | 金币扣减(账本 box.coins) | reason(hint/extra_tube), amount |
| `watersort_coin_reward` | 金币入账(首通奖励等) | amount, source |
| `watersort_tutorial_step` | 引导展示/跳过 | step_index(从 1 起)/ skipped |

**新玩法通用命名示例**(未实装前照此格式**先进本字典再写代码**):`{module}_level_start`、`{module}_level_complete`、`{module}_hint_used`、`{module}_ad_reward`、`{module}_iap_purchase`。

### 6.3 新增埋点检查清单(防再犯)
1. 起名对照硬规则:字母开头、仅 `[a-z0-9_]`、≤40,全小写 snake_case、模块前缀必带;
2. 查 §6.2 字典是否已有同语义事件(不重复造);新事件先进字典再写代码;
3. 代码侧防线已建:`AnalyticsEvents.IsValidName` 在真实现(FirebaseAnalyticsService)与桩(StubServices)入口统一校验,违规打 Warning 并丢弃——桩是开发/CI 主力,违规当场暴露而非真机静默;
4. 参数名同样须过字符限制,动态参数名取值域限 snake_case 常量;
5. 真机 DebugView 冒烟:新事件在后台可见才算上报成功。

## 7. Remote Config 与 A/B 测试

- **Remote Config 开关**:广告频控、插屏开关、提示币定价、每日挑战难度、结算弹窗样式、引导长度。
- **A/B 方向(软启动期)**:
  1. 插屏频控 4 分钟 vs 6 分钟 → 看留存 vs 收入平衡;
  2. 去广告价格 $3.99 vs $4.99;
  3. 每日挑战入口位置(主菜单 vs 结算弹窗);
  4. 讲解式提示开/关。

## 8. ASO(应用商店优化)

- **关键词**:sudoku, classic sudoku, sudoku free, brain games, number puzzle, logic puzzle, daily sudoku, offline games, sudoku no ads。
- **商店要素**:图标(辨识度高、暖色、大数字)、置顶图、截图(前 3 张决定转化)、短/长描述、宣传视频(可选)。
- **本地化商店页**:至少覆盖目标市场语言,标题/描述按语言本地化。
- **评分管理**:内置「评分引导」(完成多局且体验良好时弹),4 星以上不打扰;负面反馈收集渠道。

## 9. 增长策略(单人可控节奏)

1. **软启动(tier 2/3 市场)**:菲律宾、印尼、巴西、印度等低成本市场验证留存与 KPI,收集数据迭代。
2. **全球发布(tier 1)**:US/UK/CA/AU/DE 等,eCPM 与付费高。
3. **UA 渠道**:先 Google Ads UAC(自动投放),数据好再上 Meta;单人阶段以小预算测试。
4. **自然量**:ASO + 评分 + 「每日挑战」社交分享(分享战绩图)。

## 10. 收入预估模型(示例)

```
月收入 ≈ DAU × ARPDAU × 30
例:软启动后 DAU = 5000,ARPDAU = $0.10
   月收入 ≈ 5000 × 0.10 × 30 = $15,000/月(上限参考,需扣除服务费与税)
```

> 这是**乐观上限**参考,实际需以软启动数据回推;不建议在验证留存前投入 UA 预算。
