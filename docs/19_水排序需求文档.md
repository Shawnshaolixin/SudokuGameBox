## 1. 背景与目标

- 项目现状:数独玩法已跑通(模块骨架/存档/Addressables 管线/商业化链路),按 D-4 推荐"盒子多玩法"形态。
- 本玩法目标:用**经典水排序**(试管倒水、同色聚合)做第二个玩法,复用数独已验证的框架,补齐短会话休闲人群。
- **版本定位**:本玩法按 **v1.1 热更通道下发**——程序集走 HybridCLR 热更、资源走 Addressables 远程组;v1.0 首包**不包含**本玩法代码与资源,首包体积不受影响。
- **运营可调**:难度档位、关卡数值、广告频控**均不硬编码**,走配置(见 §8),后期运营可无热更调整。
- 与数独定位互补:数独=长时益智(10~20 分钟);水排序=短会话休闲(单局 1~5 分钟)。

## 5. 功能需求清单(带验收标准)

> 编号格式 `WS-xx`(与数独 FR-xx 区分);每条含优先级与 AC。

### 5.1 核心玩法

**WS-01 经典试管倒水对局** · P0
- AC:给定 N 支试管(N = 颜色数 + 2 空管,数值走配置),每管 4 层液体;点击源管→目标管,**一次性倒入源管顶部的整个同色连续块**(受目标管剩余容量限制),须满足"目标管顶同色且未满";**过关判定 = 所有非空管均已同色聚合(允许空管存在)**。
- AC:动画流畅(倒水 0.3~0.5s),操作反馈(选中高亮/不能倒时抖动+音效)。

**WS-02 关卡生成与可解性保证(核心算法资产)** · P0
- AC:**关卡全预生成(内容管线,非运行时)**:生成器在开发机/CI 离线批量产题 → 逐关过**求解器可解性验证** → 达标关固化 JSON 关卡数据(含难度档位、实测步数)→ 随 `Game_WaterSort` 组作 Addressables 资产下发;**玩家设备端无运行时生成器**。
- AC:生成策略 = **随机散射**构造合法混合盘 + **任意解(SolveAny)验证可解**(400ms 限时首解,实测深度 ≥ 关卡步数下限);验证不过的题**丢弃重洗,绝不下发**;同一种子产题可复现(回归可审计)。
- AC:求解器(生成期验证 / 难度步数 / 提示点位三用)须先过 **Spike 验证**——已执行完毕(结论见 §10 #1):最优解仅 ≤3 色可实时,**≥4 色不可计算**;故正式实现只保留两类求解(见 WS-03/WS-06)。

**WS-03 难度体系(配置驱动)** · P0
- AC:**档位数、每档颜色数区间、每档实测步数区间、关卡序号-难度映射一律读配置**(默认表 + Remote Config 下发),代码不硬编码任何档位数值。
- AC:**难度 = 颜色数粗筛 + 求解实测步数精控**:生成时用求解器实测步数落档,不达标重洗。实测步数指标:**≤3 色用精确最优步数;≥4 色用 SolveAny 首次解深度作代理**(最优解高色数不可计算——Spike 结论,WS-02;代理深度 ≥ 最优值,与难度单调相关,出包前用题库采样校准区间)。
- AC:默认参考值(Easy 3~4 色 / 实测 ≤15 步;Medium 5~7 色 / 15~30 步;Hard 8~10 色 / 30+ 步;前 10 关 Easy、11~40 关 Medium、41~70 关渐进、71+ 关 Hard)——作为本地默认表,运营可覆盖。
- AC:新增/修改配置后无需重新出包即可生效(v1.1 热更配置通道)。

**WS-04 顺序推进与解锁(关卡制)** · P0
- AC:按序号顺序解锁;过关解锁下一关;进度持久化到 `watersort.*` 存档分区;重进恢复至最新未过关卡。

**WS-05 撤销 / 重置 / 重新开局** · P0
- AC:撤销回退最近一次倒入;一键重置当前管;重开当前关;撤销/重置不造成不可解死局(重置/重开即回到该关初始盘面——盘面为预生成关卡,设备端无运行时生成器)。

**WS-06 卡关保护(提示 / 额外空瓶)** · P0
- AC:卡关保护以**玩家主动求助为主**(求助按钮随时可点,不打断思考),**死局自动检测为辅**(求解器判定无解路径时自动提示);超时(默认 60s)**仅作埋点,不弹窗**。
- AC:提供 ①提示=求解器执行**任意解路径的第一步**(SolveAny ≤400ms 实时出结果;不求全局最优,提示后按新盘面重新求解取下一步)②额外空瓶=追加 1 支空管(上限由配置控制);两者为激励视频点位(WS-12),同时支持金币直购(WS-08 双通道)。
- AC:提示/额外瓶次数上限读配置,运营可调。

**WS-07 完成判定与结算** · P0
- AC:最后一管同色聚合→胜利动画→结算弹窗(用时、步数、金币奖励、下一关入口)。

**WS-08 金币奖励(共享 D-5 单货币,双通道消耗闭环)** · P0
- AC:首通奖励金币(数值走配置,默认随关卡递增 20~100);金币与数独共用 `box.coins` 存档键。
- AC:**道具双通道**:提示/额外空瓶可看激励视频(WS-12)或直接金币购买(单价走配置,默认提示 20 币/次、额外瓶 40 币/次);金币具备真实消耗闭环。

### 5.2 进度与留存

**WS-09 每日挑战(Daily Challenge)** · P0
- AC:每天 1 关固定种子挑战(按日期种子,**UTC 0 点换题**,全球同日同题);**每日题库离线预生成 ≥2 年**(与常规题库同一生成管线 + 逐关可解性验证,作 Addressables 资产随远程组下发,按日期取关即可,运行时零生成风险);当日题缺失/损坏时兜底取库内备用条目(杜绝"全球同日死局");完成后计入连续天数 Streak;补签(P1,激励视频)。

**WS-10 统计面板** · P1
- AC:已通关数、总用时、总步数、每日挑战连胜;数据持久化到 `watersort.*` 分区。

**WS-11 成就(通用成就服务)** · P1
- AC:**数独先落地通用成就服务**,水排序复用;≥8 个成就(首通/连过 N 关/不用撤销过 10 关/每日挑战 7 连等)。

### 5.3 系统与体验

**WS-12 商业化(广告,频控运营可调)** · P0(激励)/ P1(插屏)
- AC(激励):三个点位——额外空瓶(默认 ≤2 次/关)、提示(默认 ≤3 次/关)、结算翻倍金币(默认 1 次/关);**各点位次数上限读配置**,运营可调;展示前完成 UMP 同意;奖励真实发放;**去广告用户激励点位直接发放**(伪视频秒完成)。
- AC(插屏):仅"关卡完成→返回关卡选择"路径展示,**连关路径(结算→直接下一关)不插屏**;**频控计时全局共享**(两玩法同一计时器,跨玩法不超频),间隔读配置(默认 ≥4 分钟 1 次);冷启动保护(新用户前三关不展示)。

**WS-13 去广告 IAP(共享)** · P0
- AC:与数独共用同一 Remove Ads 非消耗商品;购买一次两玩法都生效;支持恢复购买;去广告后激励点位直接发放(见 WS-12)。

**WS-14 新手引导(Onboarding)** · P0
- AC:首次启动 ≤3 步(点击倒水/同色聚合/卡关求助),可跳过;引导期间无广告;引导步数走配置。

**WS-15 主题与深色模式** · P1 —— 复用数独主题框架;液体颜色须与主题联动。

**WS-16 设置** · P0 —— 音效/BGM/震动开关、重置本地进度、隐私政策入口、删除本地数据、语言切换(P1 启用)。

**WS-17 本地化(i18n)** · P1 —— 首期英文可发布 + 中文开发文案;文案走 L10n 表。

**WS-18 离线游玩** · P0 —— 断网完整可玩;广告位断网时优雅降级(不卡死、不白屏);**热更玩法入口断网降级**:资源未下载时入口可见,点击弹"需联网下载"+ 重试,静默重试 1 次后报错;**已下载内容离线可玩**。

**WS-19 无障碍** · P2 —— 色盲安全(液体颜色 + 当前高度双重编码,不纯靠颜色);热区 ≥44dp。

## 10. 后续落地待办(评审已通过)

1. ~~求解器 Spike 验证~~ **已完成(2026-09-03,EditMode,`Assets/Tests/EditMode/Box.WaterSortSpike/`)**。三条结论驱动上文修订:
   - ① 玩家规则下"终态反向洗牌"生成不可行——终态零合法移动(满管禁倒空管),洗出的盘面大量锁死;生成必须走"随机散射 + 玩家规则求解器正向验证"(WS-02)。
