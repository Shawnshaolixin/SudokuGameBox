# UI 资源清单（供外部 AI 生图工具生成）

> 用途：现在项目所有界面只复用一张 Kenney 按钮图（`button_rectangle_depth_flat.png`），
> 没有大厅背景、没有对局背景、没有设置图标，面板与按钮全是一个样。
> 本清单按界面整理需要的所有 UI 资源，**能复用的只算一次**，可直接作为生图工具的规格书。

---

## 一、当前 UI 现状（为什么需要新资源）

| 位置 | 现状 | 问题 |
|---|---|---|
| 大厅 MainMenuView | 只有 Title + 4 个按钮，**无背景节点** | 界面空白无氛围 |
| 对局 GameplayView | 无背景；棋盘是运行时纯色方块（灰蓝 0.16/0.22） | 无棋盘底/宫格线，单调 |
| 全部按钮/弹窗 | 复用同一张 `button_rectangle_depth_flat.png` | 按钮、面板无法区分 |
| 设置弹窗 | 4 个开关按钮只有文字 Label，**无图标** | 需要开关样式/图标 |
| 结算弹窗 | 星级（★）用文字实现 | 需要星星图标 |
| 图标 | 旧 Kenney 图标（arrow/check/cross）风格老旧 | 整体替换 |
| Toast | 运行时黑底半透明圆角条 | 可接受，可选换贴图 |

## 二、全局规格约定（生成前必读）

| 项目 | 约定 | 说明 |
|---|---|---|
| 画布基准 | 竖屏 **1080×1920**（uiScaleMode=ScaleWithScreenSize） | 背景按这个出图 |
| 背景图尺寸 | **1080×1920**；建议 2x（2160×3840）超采样 | 全屏拉伸/平铺 |
| 按钮/面板 | **256×128 起**，9-slice 圆角矩形 | 中间区域可拉伸 |
| 弹窗面板 | 512×512 或 768×768，大圆角，9-slice（边框 ≥ 96px） | 中空填充区可拉伸 |
| 图标 | 透明底 PNG，**256×256**（2x: 512×512） | 线稿或扁平色块 |
| 棋盘底 | **900×900**（含宫格线/边框） | 与 prefab BoardPlaceholder 一致 |
| 命名后缀（CI-2 校验） | 必须以 **`_bg` / `_btn` / `_panel` / `_icon` / `_particle`** 结尾 | 否则 Jenkins 资产校验拦截 |
| 主题色 | 品牌蓝 `(0.35,0.60,0.95)`；面板浅色 `(0.96,0.96,0.98)`；深色主题钮 `(0.22,0.42,0.72)` | 与 UITheme.cs 常量一致 |
| 风格关键词 | 扁平 / 柔和渐变 / 大圆角 / 休闲手游 / 低饱和 | 可参考 `tools/prompt_library.md` |

> 放图路径：`Assets/Art/UI/{Backgrounds,Buttons,Panels,Icons}/`，生成后执行
> `Box/Phase6/4. Ensure Art Assets Registered` 注册 Addressables。

## 五、生成后的接入方式（简要）

1. **放文件**：`Assets/Art/UI/{Backgrounds,Buttons,Panels,Icons}/`，命名带 `_bg/_btn/_panel/_icon` 后缀。
2. **注册资源**：Unity 菜单 `Box/Phase6/4. Ensure Art Assets Registered`（Addressables 自动收录 Assets/Art 下 png）。
3. **替换主题**：改 `Assets/UI/UITheme.cs` 的 `ButtonTex` / `PanelTex` 常量指向新图。
4. **替换 prefab**：各 prefab 的 Image 组件 `Sprite` 需重新指定（文件 guid 变化）。
5. **接入棋盘底/开关**（可选）：需小改 `GameplayView.BuildBoardCells` / 设置弹窗，改后必须编译验证（Unity CLI batchmode，见 AGENTS.md 规则 3）。
