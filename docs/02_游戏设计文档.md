## 1. 核心玩法循环(Core Loop)

```
选难度 → 开始对局 → 观察/推理 → 填数/笔记 → (卡住)用提示 → 完成 → 结算(成绩/统计/成就)
                                    ↑                                  ↓
                              (错误检测/撤销)                (可选)看激励视频得奖励
                                                                    ↓
                                                         (完成一局后)插屏广告 → 返回主菜单/下一局
```

- **会话时长目标**:Easy 3~6 分钟 / Medium 5~10 分钟 / Hard 10~20 分钟。
- **奖励节奏**:每局完成给「提示币」;连续完成触发 Streak 加成;每日挑战给额外奖励。

## 2. 难度体系设计

### 2.1 六档难度定义

| 档位 | 目标技巧层级(由低到高) | 目标解题时间(中位玩家) | 空位数(参考区间) |
|---|---|---|---|
| Beginner | Naked Single / Hidden Single | 2~4 分钟 | 30~36 |
| Easy | + Naked Pair / Pointing | 3~6 分钟 | 36~42 |
| Medium | + Hidden Pair / Claiming / Naked Triple | 5~10 分钟 | 42~48 |
| Hard | + X-Wing / Hidden Triple | 8~15 分钟 | 46~52 |
| Expert | + Swordfish / XY-Wing / XYZ-Wing | 15~30 分钟 | 50~55 |
| Master | + 高级链/ALS 等 | 30 分钟+ | 52~58 |

> 空位数为参考,实际以**解题所需最高技巧等级 + 候选数分支数**综合评分(见 §3.3),避免「空位多但很简单」的误判。

### 2.2 设计原则
- 每档难度内谜题**难度波动小**,玩家感知稳定。
- 禁止出现「试错/猜测才可解」的谜题(逻辑可解性优先)。
- 谜题默认**对称挖洞**(旋转/镜像对称),视觉美观;可配置开关。

## 3. 数独算法设计(核心资产)

> 实现为纯 C# 模块 `SudokuCore`(无 Unity 依赖),可单元测试。详见 [03_技术架构.md](./03_技术架构.md) §4。

### 3.1 求解器(Solver)
- **逻辑求解器**:按技巧层级顺序求解(Naked/Hidden Single → Pair → Pointing/Claiming → Triple → X-Wing → Swordfish → 高级技巧),记录每一步使用的技巧,用于难度评分与「讲解式提示」。
- **回溯兜底(Backtracking)**:逻辑卡死后用「候选数最少优先 + MRV 启发式」回溯,保证最终有解判定。
- **唯一解校验**:回溯求解时统计解数;解数 > 1 立即判定「多解」并丢弃重生成。

### 3.2 生成器(Generator)
1. 生成一个随机**完整终盘**(对角拉丁方 + 洗牌/行列宫交换等保有效性变换)。
2. **挖洞**:按对称模式逐步移除数字。
3. **唯一解校验**:每次/每批挖洞后跑求解器确认仍唯一解,多解则回填或重挖。
4. **难度评分**:用逻辑求解器解当前谜题,取「所需最高技巧等级」为难度主指标。

### 3.3 难度评分公式(建议)
```
score = 1000 * (最高技巧等级) + 100 * (总解题步数) + 10 * (空位数) - 分支惩罚
```
- 将连续 score 区间映射到六档难度。
- **必须**用「最高技巧等级」作为硬门槛:例如 Hard 档不得出现 Swordfish 级技巧。

### 3.4 提示引擎(Hint Engine)
- 基础提示:对当前棋盘跑逻辑求解器,取「下一步」格,直接填数。
- 讲解提示(P1):返回 `{ 格子坐标, 填入值, 技巧名, 相关格子集合 }`,UI 高亮相关格并显示文字。

### 3.5 性能预算
- 单谜题生成 + 唯一解校验 + 评分:Editor ≤ 200ms,中端真机 ≤ 500ms。
- 采用「预生成种子库(按日期/难度)+ 运行时生成」双轨,避免主线程卡顿。

## 4. 交互与 UX 流程

### 4.1 选格与填数
- 点击格选中;再点击底部数字盘输入;**笔记模式**切换后数字盘变为候选数。
- 已有数字(给定数)不可修改;玩家填入数可改可删(橡皮擦)。
- 填完最后一位且正确 → 播放胜利动画 → 结算弹窗。

### 4.2 防误触
- 数字盘热区 ≥ 44dp;点击与滑动区分;快速双击不重复输入。
- 「撤销」手势:支持实体返回键回退一步(Android back 处理)。

### 4.3 状态机
```
MainMenu → LevelSelect(Difficulty) → Playing → Pause → (Resume | Restart | Quit) → Result → (Next | Home)
```

## 5. UI/UX 结构(线框说明)

| 界面 | 关键元素 |
|---|---|
| 主菜单 | 每日挑战入口、难度选择、统计、设置、主题切换 |
| 游戏盘面 | 9x9 网格、顶部计时/难度/连击、底部数字盘(1-9 + 笔记/撤销/擦除/提示)、提示币余额 |
| 结算弹窗 | 用时、PB 对比、连击、成就进度、激励视频翻倍奖励入口、下一局 |
| 每日挑战 | 日期日历、Streak 火焰、当日难度与奖励 |
| 统计 | 总局数/胜率/各难度柱状/最佳时间/连击 |

- 视觉风格:**极简扁平 + 暖色**,低干扰,强对比,避免「广告感」。
- 深色模式为默认推荐(数独玩家偏好)。

## 6. 视觉与音频

- **视觉**:扁平几何、卡片化;主题色可换;色盲安全色板(不依赖红/绿单独区分冲突)。
- **音频**:数字落子轻音、填错震动/提示音、胜利音;背景音乐可选(轻爵士/氛围);所有音效可独立开关。
- **动画**:填数微缩放、胜利撒花/连线、连胜火焰;全部用 DOTween,低端机可降级。

## 7. 新手引导脚本(Onboarding)

1. 欢迎 → 「数独规则一句话」+ 3 步示例(Beginner 谜题)。
2. 教「点击格子 → 底部选数字」。
3. 教「笔记模式」。
4. 教「高亮」帮助排除。
5. 教「提示」按钮(送 3 枚提示币,免广告)。
6. 完成首局 → 弹「每日挑战」入口。
- 全程可跳过、可回退、无广告;总时长 ≤ 90 秒。

## 8. 内容与关卡量

- **首版内容量**:每档难度预生成 + 运行时无限生成,保证任意难度随时可玩;每日挑战按日期种子无限供给。
- **变体路线图(P2)**:6x6(儿童/新手)、Killer Sudoku、16x16、对称美学谜题包、季节主题(万圣节/圣诞皮肤)。

## 9. 设计风险与对策

| 风险 | 对策 |
|---|---|
| 谜题「需猜测」导致挫败 | 强制逻辑可解性校验 + 讲解式提示 |
| 难度不一致 | 统一评分公式 + 大量自动化难度回归测试 |
| 提示破坏挑战感 | 提示分档:免费提示(每日)+ 激励视频;统计中标注「使用提示」 |
| 广告打断体验 | 局内零广告;插屏仅局间且频控(见 04 §3) |
