# 09 — 免费资源清单(数独 + 合成大西瓜)

> 版本:v1.1 | 用途:为「数独 + 合成大西瓜(水果合成)」找免费可商用的素材

## 0. 一句话结论

> **UI 和特效去 Kenney 下最省心**——免费、可商用、无需署名;胜利特效用 Unity Asset Store 免费「彩带庆祝」包。

## 3.1 数独专项素材(数字 + 网格 + 棋盘 UI)

> 结论:业界没有成套的"数独素材包"(已确认 OpenGameArt 搜 sudoku 仅 2 条、且都不是美术)。数独的美术需求就是**数字 + 网格线 + 棋盘 UI**,用下面的组合零成本解决:

| 用途 | 方案 | 说明 |
|---|---|---|
| **数字 1-9** | 项目已有 TMP 字体 | 字形子集已含数字(`docs/字体子集字符集.txt`),直接渲染,风格自控、零成本 |
| **9x9 格子底 / 宫格线** | Kenney **UI Pack** 面板 + UGUI `Image` 拉 1px 细线 | 面板 9-slice 切图做格板,宫格线/外框用细长 `Image` 拉伸即可 |
| **选中格高亮 / 同数字高亮** | 半透明圆角方块(自绘 1 张或 UI Pack 面板改色) | 只改 `Image` 颜色即可,无需美术 |
| **错误提示色** | `Image` 颜色配置 | 代码里换色,不用素材 |
| **撤销 / 橡皮 / 提示 / 笔记 / 计时器图标** | Kenney **Board Game Icons** / **Game Icons** | CC0,直接当按钮图标 |
| **难度选择 / 结算弹窗** | Kenney **UI Pack** | 复用主菜单面板 |
| **铅笔笔记小数字** | TMP 缩小字号 | 用 `<size=70%>` 富文本或小号字体实现 |

## 4. 在 Unity 里怎么用(新手向)

### 4.1 下载与导入
1. 从上面链接下载 `.zip`,解压;
2. 把需要的 PNG 拖进 Unity,例如放到 `Assets/Art/UI/`、`Assets/Art/Effects/`;
3. 选中 PNG,Inspector 里设置:
   - `Texture Type` = **Sprite (2D and UI)**;
   - 按钮/面板用:再设 `Sprite Mode` = **Multiple**(多图)或 Single,必要时点 `Sprite Editor` 切图。

### 4.2 按钮/面板:9-slice 切图(做出圆角、可拉伸的背景)
1. 选中 UI 背景图 → `Sprite Editor` → 设置 `Border`(9-slice 边框);
2. 把切好的 Sprite 赋给 Button 的 `Image`/`Sprite`;
3. `Image Type` = **Sliced**,按钮就能任意拉伸且圆角不变形。

### 4.3 图标
- 直接赋给对应按钮/文本前的 Image 即可(单张 Sprite)。

### 4.4 特效
- **最快**:安装 Unity Asset Store 的「Procedural Confetti」包,把 Prefab 拖到胜利结算处;
- **自定义**:`GameObject → Effects → Particle System`,把 Kenney Particle Pack 里的贴图设为 Particle 的材质/纹理,调大小、速度、重力即可。

## 5. 许可证速查

| 来源 | 许可 | 能商用吗 | 要署名吗 |
|---|---|---|---|
| Kenney | CC0(公有领域) | ✅ 可以 | ❌ 不用 |
| **Twemoji(水果贴图主食方案)** | 图像 CC-BY 4.0 / 代码 MIT | ✅ 可以 | ✅ **要**(README 或"关于"页提一句) |
| **Noto Emoji(水果备选)** | OFL 1.1 | ✅ 可以(闭源商用 OK) | 建议保留版权声明 |
| Unity Asset Store 免费包 | 看具体资产页(一般限 Unity 内使用) | ✅ 一般可以 | 看说明 |
| OpenGameArt(Fruit icons redo 等) | CC0 / CC-BY 3.0 / CC-BY-SA 3.0 混杂 | ⚠️ 逐个看 | 部分要(SA 的**不能**进闭源游戏) |
| itch.io 水果包 | 每个资源不同 | ⚠️ 逐个看 | 部分要 |

> 上架前建议**对最终使用的每个素材再确认一次许可证**,尤其是 OpenGameArt(许可混杂)与 itch.io。
> 惯例做法:在游戏"设置 → 关于"页列一个素材署名区(如 "Fruit sprites by Twitter/Twemoji, CC-BY 4.0"),一次写上所有需署名的资源。

## 6. 与工程的对接

### 数独
- 数字直接用 TMP 组件渲染(1-9),网格线/格子用 `Image` 拉伸 + `Theme.cs` 配色,无需任何美术图;
- 按钮图标导入后替换 `Theme.cs` 里的颜色,或在视图里用 Sprite 代替纯色 `Image`;
- 特效接在 `SudokuGameController.CheckFinish()` 的胜利分支(`GameFinished` 事件)处触发。

### 合成大西瓜(新玩法)
- Twemoji 水果图下载后放入 `Assets/Art/Fruits/`,导入设置 `Texture Type = Sprite (2D and UI)`;
- 每种水果对应一个尺寸档位(樱桃最小、西瓜最大),按直径递增缩放显示即可;
- 记得在"设置 → 关于"页加素材署名(Twemoji CC-BY 4.0);
- 这些属于「美术资源落地」,如需 AI 直接帮你导入和建物体,才是 MCP Unity 工具的用武之地。
