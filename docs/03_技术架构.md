## 2. 架构模式

采用**分层 + 依赖注入 + 单向数据流**:

```
┌─────────────────────────────────────────────┐
│  Presentation 层(Unity Views / MonoBehaviours)│  UI 显示、输入、动画
├─────────────────────────────────────────────┤
│  Application 层(UseCases / Services)         │  游戏流程、广告、IAP、存档、埋点
├─────────────────────────────────────────────┤
│  Domain 层(SudokuCore,纯 C#)                 │  生成/求解/难度/提示/棋盘状态
├─────────────────────────────────────────────┤
│  Infrastructure 层(平台 SDK 适配)            │  GPGS、AdMob、IAP、Firebase、存储
└─────────────────────────────────────────────┘
```

- **DI**:`VContainer`(轻量、快,推荐替代 Zenject)。
- **异步**:`UniTask`(替代协程,可取消、可测试)。
- **响应式**:`R3`(Reactive Extensions for Unity,替代 UniRx)。
- **状态管理**:对局流程用**有限状态机(FSM)**;全局状态用单例 `GameState` + 事件总线(R3)。

## 4. 核心模块设计

### 4.1 SudokuCore(纯 C#,可单元测试)
- `SudokuGenerator`(§3.2 生成器)
- `SudokuSolver`(逻辑求解器 + 回溯兜底 + 唯一解校验)
- `DifficultyRater`(评分)
- `HintEngine`(提示)
- `BoardModel`(棋盘状态、候选数、校验行/列/宫)
- **原则**:零 Unity 依赖 → 可用 NUnit 大批量回归测试(百万级谜题难度/唯一解校验)。

### 4.2 存档与持久化
- 本地:`PlayerPrefs` 仅存少量偏好;进度用 JSON 文件 + **AES 加密 + 校验和(HMAC)** 防篡改。
- 云存档(P1):GPGS Saved Games;冲突策略「取最近时间戳」。
- 时间戳签名:防改系统时间刷「每日挑战」。

### 4.3 平台服务适配器(统一接口)
- 定义 `IAdsService` / `IIapService` / `ICloudSaveService` / `IAnalyticsService`,便于测试与后续换平台。

## 6. 构建与 CI/CD

- **工具**:GitHub Actions;提交即触发 Editor 测试 + 构建 AAB。
- **签名**:启用 **Play App Signing**(Google 托管签名密钥),保留上传密钥于安全处。
- **版本语义化**:`major.minor.patch(build)`;`versionCode` 单调递增。
- **发布轨道**:internal(内部)→ closed(封闭测试)→ open(开放测试)→ production(正式)。
- **预发布报告**:每次 internal 上传启用 Play Pre-launch report 抓崩溃/性能问题。

### 6.1 构建命令(示意)
```
# Windows 命令行 / CI 中调用
Unity -batchmode -quit -projectPath . \
  -executeMethod BuildPipeline.BuildAndroidAAB \
  -logFile build.log
```

## 7. 性能与优化预算(验收)

| 指标 | 预算 | 手段 |
|---|---|---|
| 冷启动 < 2s | 启动即加载主菜单,资源异步加载 | 精简首场景、Addressables、纹理压缩 |
| 内存 < 200MB | 低端机稳定 | 对象池、UI 图集、纹理 ASTC、避免大图 |
| 首包 < 60MB | AAB 下载体积 | 压缩音频(OGG/Vorbis)、纹理压缩、精简第三方 |
| 60fps | UI 无掉帧 | Canvas 分层减少重建、合批、遮罩克制 |
| 崩溃率 ≥ 99.5% | 无崩溃 | Crashlytics + 预发布报告 + 回归 |

## 8. 安全与反作弊

- 本地存档加密 + 校验和,防篡改进度/统计。
- 时间戳 + 服务器时间(Remote Config/时间源)校验,防刷每日挑战。
- IL2CPP + 基础混淆/加固(可选),防直接反编译改逻辑。
- 广告激励奖励**服务端校验(SSV)**(AdMob 支持),防刷奖励。
- 排行榜标注「是否使用提示」,维持公平性观感。

## 9. 技术风险与对策

| 风险 | 对策 |
|---|---|
| SDK 与引擎版本兼容冲突 | 固定 SDK 版本,升级前在独立分支验证 |
| 单人维护后端无 | 无自建后端,依赖 Firebase/GPGS 托管能力 |
| 数独算法性能不达标 | 预生成种子库 + 后台/加载时生成,主线程不阻塞 |
| targetSdk 政策升级 | 每季度检查 Play 政策公告,预留升级窗口 |
