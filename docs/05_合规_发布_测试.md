## 1. Google Play 合规(发布前必须)

| 事项 | 要求 | 状态/动作 |
|---|---|---|
| Developer Program Policy | 遵守全部政策 | 发布前逐条自查 |
| **Data Safety 表单** | 如实声明数据收集/使用/分享 | 必填,涉广告 SDK 要声明 |
| **账号删除要求** | 应用内可创建账号则必须提供删除路径 | 本作无自有账号;仍提供「删除本地数据 + 删除 Play Games 数据」入口,满足精神 |
| 广告政策 | 激励视频真实发奖;插屏频控;不误导点击 | 见 04 §3 频控 |
| 儿童保护 | 不定位儿童、不选 Families、不收集儿童数据 | 内容分级选「成人/一般」,避免 COPPA |
| 内容分级(IARC) | 完成 IARC 问卷获分级 | 发布前 |
| 隐私政策 URL | 有效且可访问的隐私政策链接 | 必填,见 §2 |
| 结算政策 | 数字商品走 Google Play Billing | 已用 Unity IAP |
| 服务费 | 15%/30%,订阅 15% | 财务预期已含 |

**政策参考**:[Google Play Developer Program Policy](https://support.google.com/googleplay/android-developer/answer/16313518)、[账号删除要求](https://support.google.com/googleplay/android-developer/answer/13327111)、[服务费](https://support.google.com/googleplay/android-developer/answer/112622)。

## 2. 隐私法规与数据

### 2.1 适用法规
| 地区 | 法规 | 关键义务 |
|---|---|---|
| 欧盟/英国 | GDPR / UK GDPR | 同意管理(UMP)、数据访问/删除权、隐私政策 |
| 美国(加州等) | CCPA / CPRA | 隐私通知、不出售数据、删除请求 |
| 巴西 | LGPD | 同意与删除权 |
| 日本 | APPI | 数据最小化 |

### 2.2 数据最小化原则
- 收集数据:`Advertising ID`(广告)、粗略位置(国家,用于 eCPM/本地化)、崩溃日志、匿名行为埋点。
- **不收集**:精确位置、联系人、照片、麦克风等敏感数据。
- 隐私政策需逐项披露上述 SDK 及其数据用途,并附删除/退出(opt-out)路径。

### 2.3 隐私清单模板要素
1. 数据控制者信息;2. 收集的数据类型与目的;3. 第三方 SDK 清单(AdMob/Unity Ads/Firebase/GPGS 等);4. 用户权利(访问/删除/撤回同意);5. 联系邮箱;6. 儿童声明。

## 3. 测试策略(测试金字塔)

```
        / 手动用例 \          ← 探索性、UX、多设备
       / PlayMode 测试 \      ← Unity 运行时、UI 流程
      /  EditMode 测试   \    ← SudokuCore、存档、逻辑
     /   NUnit 单元测试     \ ← 算法回归(百万级谜题)
```

### 3.1 自动化测试重点
- **SudokuCore 回归**:随机 10 万~100 万谜题断言「唯一解 + 难度评分 + 逻辑可解」。
- **存档**:序列化/加密/篡改检测。
- **状态机**:Playing→Pause→Resume/Restart/Quit 全覆盖。
- **IAP/广告**:Mock 适配器验证商品加载/购买恢复/激励发奖。

### 3.2 设备兼容矩阵(最低要求)
| 档位 | 代表机型/配置 | 关注点 |
|---|---|---|
| 低端 | 4GB RAM / 720p / Android 7-10 | 内存、启动、掉帧 |
| 中端 | 6GB RAM / 1080p / Android 11-13 | 主流体验 |
| 高端 | 旗舰 / 高刷屏 | 高刷适配、刘海屏 |

### 3.3 缺陷分级(示例)
- **P0**:崩溃/阻断主流程/无法完成对局/广告白屏 → 阻断发布。
- **P1**:主功能异常但可绕过。
- **P2**:UI/文案/次要功能。

## 4. 发布流程与轨道

1. **internal(内部)**:每日构建自动上传,启用 **Pre-launch report** 抓崩溃/兼容性。
2. **closed(封闭测试)**:邀请 20~50 名种子用户,验证引导/留存。
3. **open(开放测试)**:软启动 tier2 市场,收集 KPI(见 04 §5)。
4. **production(正式)**:灰度(staged rollout)20%→50%→100%,监控崩溃与评分,异常可回滚。
