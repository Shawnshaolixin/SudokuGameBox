## 1. 里程碑总览

> 当前执行建议:先完成 07 文档中的 Unity 2022 MVP 闭环,再回到本路线图推进每日挑战、GPGS、多语言和软启动。

```
M0 原型验证 ──▶ M1 垂直切片 ──▶ M2 MVP ──▶ M3 软启动 ──▶ M4 全球发布
 (2-3 周)      (2-3 周)        (2-3 月)     (1-2 月)      (持续)
```

| 里程碑 | 目标 | 预估 | 退出门槛(Gate) |

| M0 原型 | 验证算法与玩法手感 | 2-3 周 | 生成/求解/唯一解/难度达标,可玩 |

## 2. 里程碑详细任务分解

### M0 — 原型验证(2-3 周)
- [ ] 搭建 Unity 6.3 LTS 项目 + 架构骨架(VContainer/UniTask/R3/asmdef)
- [ ] 实现 `SudokuCore`:求解器(逻辑 + 回溯)、生成器(挖洞 + 唯一解校验)、难度评分
- [ ] 单元测试:10 万谜题唯一解/难度回归
- [ ] 最小可玩盘面(选格/填数/高亮/胜利判定)
- **验收**:任意难度可生成、可解、可完成;生成 < 200ms

### M1 — 垂直切片(2-3 周)
- [ ] 完整单局:笔记、撤销/重做、错误检测、计时
- [ ] 主菜单 + 难度选择 + 结算弹窗
- [ ] 接入 AdMob(激励视频 1 个位)+ Unity IAP(去广告 1 个商品)+ UMP
- [ ] 隐私政策页 + 设置骨架
- **验收**:从安装到完成一局 → 看激励视频 → 买去广告,全链路可跑

### M2 — MVP(2-3 月)
- [ ] 六档难度内容 + 无限生成
- [ ] 每日挑战 + Streak + 统计面板
- [ ] GPGS 成就/排行榜;主题/深色模式;新手引导
- [ ] 本地化(≥10 语言);I2 Localization 接入
- [ ] Firebase Analytics/Crashlytics/Remote Config + 全量埋点
- [ ] 数据删除入口 + Data Safety 表单 + IARC 分级
- [ ] 构建 CI/CD + 预发布报告 + internal/closed 轨道
- **验收**:通过 05 §5 Launch Checklist,封闭测试崩溃 < 0.5%

### M3 — 软启动(1-2 月)
- [ ] tier2 市场(菲律宾/印尼/巴西)开放测试
- [ ] 监控 D1/D7/会话时长/ARPDAU/eCPM/IAP 转化
- [ ] A/B:插屏频控、去广告价格、每日挑战入口、讲解式提示
- [ ] 按数据迭代:先修留存,再调变现
- **验收**:D1≥35% 且 D7≥12%(或收敛),产出投放决策

### M4 — 全球发布(持续)
- [ ] tier1 市场(US/UK/CA/AU/DE/JP)全量,灰度发布
- [ ] Google Ads UAC 小额测试,ASO 持续优化
- [ ] 内容迭代:P1/P2 功能(云存档、订阅、变体)
- [ ] 季度政策合规复查 + SDK 更新

## 3. 总工时与周期估算

| 阶段 | 乐观 | 现实(含返工) |
|---|---|---|
| 到 MVP 可测试 | 3 个月 | 4-5 个月 |
| 到软启动 | 4 个月 | 5-6 个月 |
| 到全球发布 | 6 个月 | 7-9 个月 |

> 建议按「现实」排期,单人开发返工、SDK 对接、合规反复是常态。

---

## 4. 敏捷节奏建议

- **迭代**:1 周 1 个 Sprint;周五构建 + 自查。
- **Backlog**:需求追踪矩阵(PRD §8)+ 每 Sprint 完成标准(DoD)。
- **优先级铁律**:P0 全部完成前,不做任何 P1/P2;留存不达标,不加新功能。
- **每周复盘**:看 Firebase 数据,决定下个 Sprint 方向。

---

## 5. 关键决策点(Gates)

| Gate | 位置 | 决策 |
|---|---|---|
| G1 | M0 末 | 算法手感是否合格?不合格不进入 UI 阶段 |
| G2 | M2 末 | 是否通过 Launch Checklist 上封闭测试? |
| G3 | M3 末 | 留存是否达标?→ 达标投 UA/全球;不达标继续调核心 |
| G4 | M4 | 是否值得持续运营/扩内容,或止损 |
