Rovilo

A classic Sudoku puzzle game for Android — offline, calm, and free to play.

About

Rovilo is a Sudoku game built around a clean, distraction-free grid. Puzzles are generated on-device, so the game works fully offline. Multiple difficulty levels, a daily challenge, a hint system, and no forced interruptions.
